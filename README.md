# «Меткий ответ»

Автономный редактор учебной аркады с живым предпросмотром. Учитель создаёт вопросы, выбирает оформление и персонажей, тестирует игру и скачивает готовый HTML.

## Запуск

Приложение не требует установки зависимостей.

Вариант 1: откройте `index.html` в браузере.

Вариант 2 (рекомендуется): в папке проекта выполните:

```bash
python3 -m http.server 4173
```

После этого откройте `http://localhost:4173`.

## Возможности

- четыре типа заданий: один ответ, несколько ответов, устный вопрос, порядок;
- семь языков системных надписей;
- встроенные фоны, восемь целей и восемь помощников;
- загрузка собственных PNG, JPEG, WebP и GIF;
- настройка цветов, свечения и размеров текста;
- раунды, выстрелы, скорость целей и баллы;
- стабильный предпросмотр без перезагрузки сцены;
- автосохранение черновика в браузере;
- импорт и экспорт проекта JSON;
- скачивание самостоятельного HTML-файла игры;
- копирование адаптивного `iframe srcdoc` для Genially.

## Форматы и ограничения

Файл проекта имеет расширение `.aimquiz.json`. Пользовательские изображения включаются в него как data URL, поэтому крупные изображения увеличивают файл. Размер одного загружаемого изображения ограничен 5 МБ.

Скачанный HTML автономен. Стандартный фон при автономном экспорте заменяется встроенной авторской SVG-сценой; загруженный пользователем фон сохраняется без изменений.

Genially может ограничивать размер `srcdoc`. Если код не принимается платформой, скачайте HTML, разместите его на HTTPS-хостинге и вставьте публичную ссылку через обычный `iframe`.

## Файлы

- `index.html` — разметка редактора и игрового предпросмотра;
- `styles.css` — интерфейс и игровая сцена;
- `app.js` — состояние, редактор заданий, игровая логика и экспорт;
- `assets/meadow-original.jpg` — оригинальный сгенерированный фон;
- `AI_INSTRUCTION_DUCK_HUNT_EDITOR.md` — исходное техническое задание.
