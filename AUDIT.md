# Проверка редактора — 27 сентября 2026

## Результат и границы проверки

Проверен редактор, HTML-экспорт и новая отдельная версия iframe-плеера в Chromium.
Проверка включает реальные браузерные сценарии, изменения настроек, загрузку файлов,
сохранение проекта, математическую запись и прохождение игры.
Это не проверка всех сочетаний параметров на всех устройствах: Safari, Firefox и сенсорные
устройства отдельно не проверялись. Звук проверен по вызовам аудиосистемы и параметрам
синтеза, без субъективного прослушивания.

Исходная версия: `ba214965ebfdff75253721047637bd93ef3bf034`.
Сохранены параллельные изменения: перемешивание ответов, свободный выбор траектории,
автоматическое количество заданий и опубликованные версии плеера.

## Проверки

- 191 элемент исходной разметки сопоставлен с кодом. Дополнительно в браузере изменены
  216 доступных полей: 213 меняют настройки, ещё 3 фильтруют библиотеки.
- Все 68 присутствующих ползунков проверены на минимальном и максимальном значении.
- Проверены 7 вкладок, добавление, копирование, перемещение и удаление раундов,
  подтверждение и отмена удаления, загрузка и удаление изображений и своего звука.
- Проверены кнопки скачивания проекта и HTML, оба варианта копирования кода Genially,
  сжатие проекта, отмена/повтор действий, повторная загрузка одного проекта.
- Проверены сохранение и восстановление последнего проекта, включая проект больше 6 МБ.
- Реальными движениями мыши проверены независимое перетаскивание помощника и облака,
  а также изменение размера помощника за угол.
- Проверены формулы, игровые траектории, количество целей по уровню, разлёт целей,
  задержка целей и прицела до окончания надписи раунда, повторный запуск.
- Для десяти звуковых пресетов совпадают параметры синтеза в редакторе и HTML.
- 20 изолированных проверок игровой логики проходят.
- Браузерные наборы: latex, export, history-reset, project-load, target-library,
  runtime-parity, requested-fixes, v8, audio-parity, audit-ui, result-button,
  header-actions, pinned-player. Подробные результаты сохраняются в `tests/audit-results.json`.

## Исправления

| Область | Исправление |
|---|---|
| Кнопка «Играть снова» | HTML применяет сохранённый цвет кнопки отдельно для победы, поражения и окончания времени |
| Загрузка своего звука | Обработчик получает файл из правильного элемента input |
| Итоговый экран | Размер заголовка и анимация применяются в обоих вариантах игры; настройки остаются доступны после загрузки/удаления картинки |
| Траектории в предпросмотре | Персонажи используют выбранную траекторию и длительность, как в игре |
| HTML-таймер | Обновляются секунды, шкала и предупреждение; ноль отображается как 00:00 |
| Общий таймер | «Продолжить» останавливает только таймер отдельного задания |
| Жизни | Выключенные жизни не отображаются и не теряются |
| Ответы | Повторный Enter после верного ответа не начисляет очки снова |
| Раунды | Новый раунд начинается с первого задания; выбор раунда обновляет активные задания |
| Перезапуск | Возвращаются первый раунд и начальный экран |
| Удаление | Удаление раунда не подменяет общий обработчик; работают динамические кнопки удаления картинок |
| Эффекты попадания | В редакторе и HTML используется общая функция частиц |
| Предпросмотр | Переход к редактированию останавливает запущенный тест |
| Звуки | Подключены события кнопки, появления цели и выстрела; громкость 0 означает тишину |
| Числовые поля | Соблюдаются границы значений, включая количество целей и интервал сложности |
| Язык | Названия уровней слушают оба существующих переключателя языка |
| Настройки | Скрыты устаревшие поля, переопределяемые редакторами сложности и раундов |

## Математическая запись

Проверены дроби, вложенные корни, степени, модуль, системы, математические символы,
безопасное отображение HTML-символов и разделение вариантов ответа с `|` внутри формулы.
Поддерживаются `$...$`, `$$...$$`, `\(...\)`, `\[...\]`, `\dfrac`, `\tfrac`,
распространённые операторы и текстовые команды. Это компактный набор LaTeX, не полный TeX.
В HTML встраивается тот же рендерер.

## Защита опубликованных игр

Новая версия: `game-v20260926-audit1.html` → `player-v20260926-audit1/`.
Существующие `game-v*.html` и `player-v*/` не меняются.
Старый `game.html` сохраняет прежний адрес плеера; прямой `index.html?player=1`
закреплён за снимком `player-v20260926-5`, соответствующим предыдущему редактору.

Старые игры сохраняют и прежнее поведение, и прежние ошибки. Чтобы применить исправления
к конкретной презентации, нужно явно заменить её код вставки. Новые настройки редактора
сами по себе опубликованную игру не меняют.
